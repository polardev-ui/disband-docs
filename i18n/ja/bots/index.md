# ボット

Disbandボットは自己ホストされた統合です。 あなたはコードを実行し、Disbandはそのコードとの間でメッセージを中継します。 Disbandは、ボットのコードをホストしたり実行したりすることはありません。

## 仕組み

1. **設定→ボット**で**ボットを作成**し、必要な範囲を選択します。 あなたは得る
   トークンが返されます。**1回**表示されます。
2. **設定→ボット**で、必要なサーバーの**招待リンク**を生成します。
   参加するためのボット、そしてそのサーバーの**所有者**に送信します。
3. オーナーはリンクを開き、承認します。ボットはサーバーのメンバーになります。
4. クライアントライブラリをどこかに（サーバー、クラウド機能など）実行します。
   あなたのラップトップ）と、トークンでDisbandに接続します。

## スコープ

ボットのサーバーでの範囲は、ボットを作成するときに要求した範囲と、所有者がその特定のサーバーに承認した範囲の**交差点**です。

| 範囲             | 説明                                                          |
| ----------------- | -------------------------------------------------------------------- |
| `messages.read` | ゲートウェイでメッセージイベントを受信し、メッセージ/チャンネルを読み取ります。 |
| `messages.write` | ボットが見ることができるチャネルでメッセージを送信し、返信します。 |
| `members.read` | ボットが参加したサーバーのメンバーをリストアップします。                      |
| `channels.manage` | チャンネルを作成、名前を変更、削除します。サーバーでは`manage_channels`の役割も必要です。|

## トークン認証

すべてのAPIコールは、ボットトークンで認証されます。

```
Authorization: Bot <token>
```

ボットトークンは**休止中にハッシュされます**。生のトークンは保存されたり、取得されたりすることはありません。漏洩した場合（またはボットがもう必要ない場合）、**設定→ボット**で取り消します。取り消しにより、トークンはすぐに削除されます。

## 制限と安全

- アカウントあたり最大**5つのボット**。ボットはいつでも取り消すことができ、その機能が失われます。
  トークン。
- **4,000文字**までのメッセージ。ボットには`mention_everyone`ロールが必要です
  `@everyone`の使用許可。
- ボット招待を承認できるのはサーバーの**所有者**だけです。招待は後で期限切れになります
  **7日間**。
- ボットトークンは休止時にハッシュされます。生のトークンは保存されたり、取得されたりすることはありません。
- ボットは決してデータベースに直接アクセスすることはできません。すべてのアクションはスコープを経由します。
  APIエンドポイント。
