# 開発者

Disbandの上に構築します。ボット、統合、および外部からスペースと対話するツールです。ここにあるすべてはセルフホストされています。Disbandは決してコードを実行しません。

## あなたが構築できるもの

- **ボット** — メッセージを読み書きし、チャネルを管理するセルフホストアカウント。
  そして、長期間のポーリングゲートウェイを介してイベントに反応します。 [ボット](../bots/index.md)を参照してください。
- **Webhooks** — ボットなしで秘密のURLを介して投稿された一方通行の通知
  コードまたはトークン。[Webhook](webhooks.md)を参照してください。
- **埋め込みカード** — 構造化されたリリースノート、アラート、ステータス更新。
  [埋め込み](embeds.md)を参照してください。
- **カスタムクライアント** — 必要な言語が必要な場合は、HTTP APIに直接ご連絡ください。
  出荷されたクライアントはカバーされません。[APIリファレンス](../bots/api-reference.md)は
  契約書。
- **ステータス統合** - RSSを介してDisbandのインシデントをフォローするか、どのように行うかを読んでください。
  [ステータスシステム](status.md)はチェックを記録し、インシデントを開きます。

## ここから始めましょう

1. **[はじめに](../bots/getting-started.md)** — ボットを作成し、その
   トークン、それをスペースに招待します。約2分です。
2. **[独自のボットをホストする](../bots/hosting-your-own-bot.md)** — 実行場所
   クライアントとそれを生き続ける方法。
3. **[JavaScript](../bots/clients/javascript.md)**または
   **[Python](../bots/clients/python.md)**。
4. **[APIリファレンス](../bots/api-reference.md)**は、正確なエンドポイントです。
5. **[Webhook](webhooks.md)** または **[埋め込み](embeds.md)** が必要な場合は
   一方通行の通知。
6. **[ステータスシステム](status.md)**は、公開ステータスページとRSSフィードに使用されます。

## Disbandをゲームやアプリに実装する

Disbandは、ボットトークンで認証されたプレーンHTTP APIを公開しています。ネイティブのSDKやRPCランタイムはありませんが、HTTPSリクエストを実行できるスタックはすべて機能します。典型的な統合は次のようになります。

1. **設定→ボット**でボットを作成し、`messages.write`を割り当てます（および
   `channels.manage`はチャンネルを作成する必要がある場合）。
2. 投稿したいスペースにボットを招待します。
3. トークンをゲームまたはアプリの秘密ストアに保存します。クライアント側には保存しないでください。
   プレイヤーに送信されるコード。
4. バックエンドから、スコープされたエンドポイントに呼び出します。

   ```bash
   curl -X POST https://www.disband.dev/api/v1/channels/CHANNEL_ID/messages \
     -H "Authorization: Bot $DISBAND_BOT_TOKEN" \
     -H "Content-Type: application/json" \
     -d '{"content": "Server restarted — 12 players online."}'
   ```

5. ゲーム内からのチャットに反応するには、ゲートウェイを長時間ポーリングして送信します。
   `messageCreate`イベントをゲームロジックに追加します。

### セキュリティノート

- ボットトークンは休止時にハッシュされ、一度だけ表示されます。 1 つがある場合はすぐに取り消してください。
  漏れ。
- トークンを管理するサーバーに保管します。ゲームクライアントでトークンを送信すると、
  誰かがあなたのボットを偽装する。
- ボットを必要な最小限の特権に制限します。投稿専用ボットは必要ありません
  `members.read`または`channels.manage`。
