# 봇

Disband 봇은 자체 호스팅된 통합입니다. 코드를 실행하고, Disband는 메시지 주고받습니다. Disband는 절대 당신의 봇의 코드를 호스팅하거나 실행하지 않습니다.

## 그것이 어떻게 작동하는가

1. **설정 → 봇**에서 **봇 생성**하고 필요한 스코프를 선택하세요. 당신은 얻게 됩니다.
   토큰 반환 - **한 번** 표시됩니다.
2. **설정 → 봇**에서 원하는 서버에 대한 **초대 링크**를 생성합니다.
   가입할 봇과 그 서버의 **소유자**에게 보내세요.
3. 소유자가 링크를 열고 승인을 합니다. 봇은 서버의 회원이 됩니다.
4. 당신은 클라이언트 라이브러리 중 하나를 어딘가에 실행합니다(서버, 클라우드 함수,
   당신의 노트북) 그리고 그것은 토큰과 함께 Disband에 연결됩니다.

## 스코프

서버에서 봇의 스코프는 **상호**로, 봇을 생성할 때 요청한 스코프와 소유자가 해당 특정 서버에 대해 승인한 스코프입니다.

| 스코프             | 설명                                                          |
| ----------------- | -------------------------------------------------------------------- |
| `messages.read` | 게이트웨이에서 메시지 이벤트를 수신하고 메시지/채널을 읽습니다. |
| `messages.write` | 봇이 볼 수 있는 채널에서 메시지에 보내고 답장하세요.              |
| `members.read` | 봇이 가입한 서버의 멤버들을 나열합니다.                      |
| `channels.manage` | 채널 생성, 이름 변경, 삭제 - 서버에서 `manage_channels` 역할도 필요합니다. |

## 토큰 인증

모든 API 통화는 봇 토큰으로 인증됩니다:

```
Authorization: Bot <token>
```

봇 토큰은 **휴지 상태에서 해시됩니다** - 원시 토큰은 저장되거나 검색할 수 없습니다. 유출되면(또는 더 이상 봇이 필요하지 않다면) **설정 → 봇**에서 취소합니다. 취소는 토큰을 즉시 삭제합니다.

## 제한 및 안전

- 계정당 **최대 5개의 봇**. 봇은 언제든지 취소할 수 있으며, 이는 봇의
  토큰.
- **4,000자**까지 메시지. 봇은 `mention_everyone` 역할을 필요로 합니다.
  `@everyone` 사용 허가.
- 봇 초대장을 승인할 수 있는 사람은 서버의 **소유자**뿐입니다. 초대장은 다음 이후 만료됩니다.
  **7일**.
- 봇 토큰은 휴지 상태에서 해시됩니다; 원시 토큰은 저장되거나 검색할 수 없습니다.
- 봇은 절대적으로 데이터베이스에 직접 접근할 수 없습니다. 모든 행동은 스코프 내에서 진행됩니다.
  API 엔드포인트.
