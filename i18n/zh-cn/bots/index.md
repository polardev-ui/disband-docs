# 机器人

Disband机器人是自托管的集成。你运行代码，Disband负责在代码与服务器之间传递消息。Disband从不托管或执行你的机器人的代码。

## 它是如何工作的

1. 在**设置→机器人**中创建一个机器人，并选择它需要的作用域。你将得到
   一个代币返回——它显示**一次**。
2. 在**设置→机器人**中，为你想要的服务器生成一个**邀请链接**
   加入机器人，并将其发送给该服务器的**所有者**。
3. 所有者打开链接并批准。机器人成为服务器成员。
4. 你在某个地方运行其中一个客户端库（服务器、云函数，
   你的笔记本电脑）并用令牌连接到Disband。

## 界限

机器人的服务器作用域是你创建机器人在创建时请求的作用域和所有者批准的特定服务器作用域的**交集**：

|作用域             |描述                                                          |
| ----------------- | -------------------------------------------------------------------- |
| `messages.read` | 在网关上接收消息事件并读取消息/频道。 |
| `messages.write` | 在机器人可以看到的频道中发送和回复消息。 |
| `members.read` | 列出机器人加入的服务器成员。                      |
| `channels.manage` | 创建、重命名和删除频道——还需要服务器中的`manage_channels`角色。 |

## 令牌认证

每次API呼叫都使用机器人令牌进行身份验证：

```
Authorization: Bot <token>
```

机器人代币是**静态哈希的**——原始代币永远不会被存储或检索。如果它泄露（或者你不再需要机器人），请在**设置→机器人**中撤销它；撤销会立即杀死代币。

## 限制和安全

- 每个帐户最多**5个机器人**。机器人可以随时被撤销，这会杀死它的
  代币。
- 消息最多**4,000个字符**。机器人需要`mention_everyone`角色
  使用`@everyone`的许可。
- 只有服务器的**所有者**才能批准机器人邀请。邀请将在之后到期
  **7天**。
- 机器人代币在静止状态下进行哈希；原始代币永远不会被存储或检索。
- 机器人永远无法直接访问数据库——每项操作都必须经过作用域限制
  API端点。
